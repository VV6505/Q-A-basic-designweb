# Quiz 240 câu — Nano & Nanomedicine

Bộ quiz được tạo từ `Câu hỏi.pdf` (240 câu, A/B/C/D và đáp án đúng theo tài liệu gốc).

## Cách dùng
1. Mở `quiz.html` bằng Chrome/Edge.
2. Chọn số câu và thứ tự.
3. Chọn A/B/C/D. Hệ thống chấm **ngay sau từng câu**.
4. Cuối bài xem tổng điểm và câu đúng/sai.

Không cần Internet, Node.js hay cài server.
